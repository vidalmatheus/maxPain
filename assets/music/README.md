`web/` holds a ~100 s mono loop of each for the browser build (see
`autoload/music.gd`). Both versions are made from the original MP3s with
[`tools/prepare_music.sh`](../../tools/prepare_music.sh) (loudness normalized)
from the original downloads.

The original Max Payne soundtrack is not included: it is copyrighted by its
owners and can't be redistributed with this project.
