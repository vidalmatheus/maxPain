# Environment models

The street is built in code (`scenes/levels/street_level.gd`) from models by
[Kenney](https://kenney.nl), all [CC0](https://creativecommons.org/publicdomain/zero/1.0/)
(public domain). Downloaded in October 2026; only the models the level uses
are included.

| Folder | Kit | Models |
|---|---|---|
| `cars/` | [Car Kit](https://kenney.nl/assets/car-kit) | police, sedan, taxi, van, SUV, hatchback |
| `city_roads/` | [City Kit (Roads)](https://kenney.nl/assets/city-kit-roads) | road tiles, street lamps, dumpster, construction barrier and cone, traffic light, signs |
| `city_buildings/` | [City Kit (Commercial)](https://kenney.nl/assets/city-kit-commercial) | buildings and skyscrapers |

Each kit shares one `Textures/colormap.png`. The level scales the models to
real-world size and darkens the buildings for the night look.
